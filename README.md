# VK Bot Guard

Небольшой модератор для **одной VK-беседы**.

## Правило

- первое сообщение пользователя — разрешено;
- второе сообщение, если с первого прошло меньше 1 часа:
  - сообщение удаляется из беседы;
  - пользователь получает ограничение на отправку сообщений на 1 час;
  - публичное уведомление в беседу не отправляется;
  - бот пытается отправить пользователю уведомление в личные сообщения;
- после истечения часа новое сообщение снова становится первым;
- пользователь в ограничении не меняет таймер;
- администраторы из `ADMIN_IDS` исключены.

Это **скользящее окно 60 минут**, а не календарный час.

> Личные сообщения от сообщества зависят от настроек VK и разрешений пользователя. Если VK не разрешает сообществу написать пользователю, модерация всё равно выполняется, а причина фиксируется в логе.

## Стек

- Python 3.10+
- `vk-api`
- SQLite
- VK Community Long Poll

## Настройка VK

1. Создайте ключ сообщества с правами, необходимыми для работы с сообщениями.
2. Включите сообщения сообщества и Long Poll.
3. Добавьте сообщество в нужную беседу.
4. Назначьте сообщество администратором беседы и выдайте права на управление перепиской.
5. Укажите `VK_TOKEN` и `GROUP_ID` в локальном `.env`.

## Запуск

```text
pip install -r requirements.txt
copy .env.example .env
python bot.py
```

Для Windows можно использовать `start.bat`.

## Тесты

```text
python -m unittest discover -s tests -v
```

## Безопасность

- настоящий `.env` не должен попадать в Git;
- SQLite-база и логи не должны попадать в Git;
- если токен когда-либо попал в публичный репозиторий, его нужно **немедленно отозвать/перевыпустить** в VK. Удаление файла из последующего коммита не делает старый токен безопасным.

## Ограничения концепта

Бот специально прост: один чат, одно правило, SQLite. Не нужно добавлять PostgreSQL, Redis, очереди или сложную архитектуру, пока не появится реальная нагрузка или новые правила.
